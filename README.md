# Kakao Relay Beta

Public, static demand test for a customer-owned Android notification relay.

This repository intentionally contains no Android application source, device
data, webhook endpoints, credentials, or payment integration. Its public page
states the experiment boundary and offers a privacy-minimising interest form.

The experiment is free. Optional voluntary support is disabled until a human
operator has completed receiving-account setup, and it never unlocks a feature,
beta access, support priority, or a licence.
