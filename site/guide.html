Kakao Relay Beta 사용처 안내

PUBLIC BETA GUIDE

알림을 옮긴다는 말의
실제 범위.

“카카오톡을 Discord나 Telegram으로 보낸다”는 말은 쉽게 오해될 수 있습니다. 이 페이지는 Kakao Relay Beta가 무엇을 검증하고, 무엇을 아직 제공하지 않는지 설명합니다.

01 · DEFINITION

이 실험의 전달은 Android 알림에서 시작합니다.

이 실험이 검증하는 것은 고객이 소유한 Android 휴대폰에서, 사용자가 명시적으로 알림 접근 권한을 준 뒤 선택한 카카오톡 알림을 자신이 정한 목적지로 전달하려는 수요입니다. 카카오톡 서비스에 서버 방식으로 접속하거나 대화 데이터를 읽는 방식이 아닙니다.

02 · CONTROL

선택과 목적지는 기기 소유자가 통제합니다.

A

알림 접근

사용자가 Android 설정에서 권한을 직접 부여할 때만 시작할 수 있습니다.

B

대화 선택

전달할 카카오톡 대화는 사용자가 직접 고르는 범위 안에 있어야 합니다.

C

내 목적지

Telegram, Discord 또는 사용자가 소유·관리하는 HTTPS webhook이 전달 후보입니다.

03 · BOUNDARY

공식 통합이나 원격 답장을 약속하지 않습니다.

이것은 아닙니다

  • 카카오톡 공식 API 또는 공식 봇
  • 카카오톡 로컬 데이터베이스를 읽는 제품
  • 공개 베타에서 제공하는 원격·보조 전송 또는 답장

이 양식이 요청하지 않는 것

  • 카카오 ID, 전화번호, 개인 이메일
  • 알림·대화 내용, 기기 일련번호
  • Webhook URL, 토큰, 비밀값

04 · READINESS

아직 설치 파일을 약속하지 않습니다.

현재 공개 단계는 수요 검증입니다. 서명된 수동 설치 베타는 실제 설치 의향이 확인된 뒤에만 준비하며, 지금은 설치 시점·기능·지원·유료 혜택을 예약하거나 판매하지 않습니다.

공개 베타 관심 등록 열기 ↗

공개 양식에서는 전달 목적지, 공개 가능한 사용처 범주, 수동 설치 의향, 비구속적 가격 범위만 선택합니다. 가격 선택은 결제나 예약이 아닙니다.
