THE IDEA

하고 싶은 건 단순해요.

01

내 폰에서

사용자가 Android 알림 접근 권한을 직접 주는 방식입니다.

02

내가 고른 알림만

카카오톡 전체가 아니라, 필요한 대화의 알림만 고르는 형태를 생각하고 있어요.

03

내가 쓰는 곳으로

Discord, Telegram 또는 내가 관리하는 HTTPS webhook으로 한 방향 전달을 생각하고 있습니다.

대충 이런 식이에요.

가상의 공개 데모입니다. 이 페이지는 실제 알림을 읽거나 전송하지 않으며, 입력값·URL·토큰을 받거나 저장하지 않습니다.

Telegram으로 보이는 가상 예시

예시 대화
가상의 작성자: 오늘 3시에 확인해 주세요.

이 버튼은 화면의 가상 예시만 바꿉니다. 실제 카카오톡, Telegram, Discord, webhook 또는 외부 서버에 연결하지 않습니다.

BOUNDARY

이건 하지 않아요.

이 도구의 바깥

  • 카카오톡 공식 API 또는 공식 봇인 척하지 않습니다.
  • 카카오톡 로컬 데이터베이스를 읽지 않습니다.
  • 화면 좌표를 누르는 UI 자동화로 메시지를 보내지 않습니다.
  • 임의의 대화방으로 메시지를 보내거나 파일·이미지를 가져오지 않습니다.
  • 공개 베타에서 원격·보조 전송 기능을 제공하지 않습니다.

처음부터 받지 않는 것

  • 카카오 ID, 기기 일련번호, 알림·대화 내용
  • Webhook 비밀값, Telegram 봇 토큰, Discord webhook URL
  • 베타 관심 등록을 위한 전화번호나 개인 이메일

EARLY INTEREST

이런 연결, 써볼 생각 있나요?

공개 양식에서 원하는 목적지, 공개 가능한 사용처 범주, 수동 설치 의향, 비구속적 가격 범위만 골라 주세요. 입력이 공개되니 이름·연락처·대화 내용·토큰은 적지 마세요.
