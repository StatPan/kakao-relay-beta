CUSTOMER-OWNED ANDROID RELAY

내 휴대폰의 알림을,
내가 정한 곳으로.

선택한 카카오톡 대화의 Android 알림을 Telegram, Discord 또는 HTTPS webhook으로 전달합니다. 카카오톡을 대신하는 봇도, 공식 카카오 API도 아닙니다.

무료 베타 관심 등록 지원 범위 확인

현재 상태: 공개 설치 전 수요 검증 단계입니다. 서명된 베타 설치 파일이 준비되기 전에는 설치를 약속하지 않습니다.

WHAT IT DOES

휴대폰이 직접 허용한 알림만 다룹니다.

01

선택한 대화만

사용자가 Android 알림 접근 권한을 부여하고, 전달할 카카오톡 대화를 직접 고릅니다.

02

내 목적지로 전달

Telegram, Discord 또는 사용자가 소유·관리하는 HTTPS webhook으로 서명된 이벤트를 보냅니다.

03

공개 베타의 범위

이 공개 베타는 선택한 알림의 전달 수요만 검증합니다. 원격·보조 전송은 제공하지 않습니다.

CLEAR BOUNDARY

하지 않는 일을 분명히 말합니다.

하지 않습니다

  • 카카오톡 공식 API 또는 공식 봇인 척하지 않습니다.
  • 카카오톡 로컬 데이터베이스를 읽지 않습니다.
  • 화면 좌표를 누르는 UI 자동화로 메시지를 보내지 않습니다.
  • 임의의 대화방으로 메시지를 보내거나 파일·이미지를 가져오지 않습니다.
  • 공개 베타에서 원격·보조 전송 기능을 제공하지 않습니다.

요청하지 않습니다

  • 카카오 ID, 기기 일련번호, 알림·대화 내용
  • Webhook 비밀값, Telegram 봇 토큰, Discord webhook URL
  • 베타 관심 등록을 위한 전화번호나 개인 이메일
