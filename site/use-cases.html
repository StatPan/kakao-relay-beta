USE-CASE GUIDE

알림을 다른 곳에서
다시 보고 싶은 경우.

Kakao Relay Beta는 사용자 소유 Android 기기에서 선택한 카카오톡 알림을 사용자가 관리하는 목적지로 단방향 전달하려는 수요를 확인합니다. 지금은 설치 파일이나 연결 기능을 제공하지 않는 공개 실험입니다.

WHEN IT FITS

다음과 같은 경우에만 검토할 만합니다.

01

내 알림을 내 도구에서

내 Android 기기의 선택 알림을 내가 관리하는 Telegram이나 Discord에서 다시 확인하고 싶을 때입니다.

02

제한된 자동화 연결

내가 소유·관리하는 HTTPS webhook으로, 필요한 알림 이벤트만 이어 보고 싶을 때입니다.

03

명시적 선택이 가능한 경우

Android 알림 접근 권한, 전달 대화, 전달 목적지를 기기 소유자가 직접 정할 수 있을 때입니다.

WHEN IT DOES NOT FIT

다음 기대라면 이 실험에 맞지 않습니다.

기능 기대

  • 카카오톡 공식 API 또는 공식 봇을 원합니다.
  • 원격 답장, 보조 전송, 대화방 자동 조작을 원합니다.
  • 전체 대화 기록, 파일·이미지, 백업·아카이브를 원합니다.

권한과 목적지

  • 기기 소유자가 알림 접근과 전달 대상을 직접 통제할 수 없습니다.
  • 다른 사람의 대화 내용을 알림이나 동의 없이 전달하려 합니다.
  • 목적지의 보관·공유 방식을 통제하거나 설명할 수 없습니다.

PUBLIC TEST STATUS

지금은 연결을 받지 않습니다.

이 페이지와 관심 양식은 어떤 카카오톡 계정, Android 기기, 알림 내용, Telegram·Discord 자격 증명, webhook URL도 받거나 저장하지 않습니다. 공개 양식은 수요·수동 설치 의향·비구속적 가격 반응을 확인할 뿐이며, 설치·결제·예약·이용 권한을 만들지 않습니다.
